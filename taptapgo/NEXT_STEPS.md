# Roadmap TapTapGO - Prochaines versions

## v1.1 - Améliorations UX

- [ ] Effets sonores avec Howler.js (correct, erreur, victoire, défaite)
- [ ] Animations PixiJS plus fluides (particules de victoire, transition entre phrases)
- [ ] Vibration mobile sur bonne/mauvaise réponse (`navigator.vibrate`)
- [ ] Mode sombre / clair
- [ ] Compteur de mots par minute (WPM) en temps réel

## v1.2 - Gameplay avancé

- [ ] Niveaux de difficulté (phrases courtes, moyennes, longues)
- [ ] Sélection de thèmes avant la partie
- [ ] Mode "Survie" : phrases illimitées, 3 vies
- [ ] Bonus de vitesse (combo si 3 phrases correctes d'affilée)
- [ ] Système de niveaux et XP

## v1.3 - Social

- [ ] Leaderboard global (Firebase)
- [ ] Système d'amis avec codes persistants
- [ ] Chat en salle d'attente
- [ ] Partage de résultats sur les réseaux sociaux
- [ ] Tournois hebdomadaires

## v1.4 - Contenu

- [ ] 500+ phrases supplémentaires
- [ ] Phrases en anglais (mode bilingue)
- [ ] Phrases personnalisées par les joueurs
- [ ] Thèmes saisonniers (Noël, Halloween, etc.)

## v1.5 - Technique

- [ ] Migration vers PixiJS 8
- [ ] Tests unitaires (Vitest)
- [ ] CI/CD avec GitHub Actions
- [ ] Monitoring des performances (Lighthouse CI)
- [ ] Analytics anonymes (parties jouées, temps moyen)
- [ ] Nettoyage automatique des rooms Firebase expirées (Cloud Functions)

## v2.0 - Multijoueur avancé

- [ ] Parties à 4 joueurs
- [ ] Mode spectateur
- [ ] Rooms privées avec mot de passe
- [ ] Matchmaking automatique
- [ ] Classement ELO
